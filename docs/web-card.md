# Web 自动角色卡

本版本复刻 `raw-docs/vaesen自动卡by拂晓鵺啼 v2.0.xlsx`。网页源代码在 `web/`；不依赖前端框架、在线字体或第三方计算服务。原 Excel 与规则 PDF 均未修改。

[打开网页版](https://vaesen-investigator-archive.auseaia01.chatgpt.site)（仅当前所有者可访问）。2026-10-04 发布成功，版本 1。托管内容与本仓库的网页源码一致。

## 使用

运行 `npm run dev`，打开显示的本地地址。网页从与 Excel 相同的空白角色卡开始，先填写泛型和年龄，再分配属性、技能及资源加点。剩余点数可以为负；输入不会被强制裁剪。年龄为空或低于 17 时保留原表“年龄错误”与 `#N/A`。

首项天赋下拉随泛型改变，但已填的天赋不会被静默清除。其余三个天赋槽可以自由输入，已知名称自动查说明；说明可手改，也可恢复自动查表。Excel 的精确 `VLOOKUP` 仍支持名称里的 `*`、`?` 通配符。

16 个状态与经验圆点各自支持 `○`、`●` 和留空。它们不自动扣骰或购买成长。装备、护甲、防护、武器数值、资产等保持手填。

输入自动保存于当前浏览器。导出 JSON 后可以在相同 Excel 版本的网页导入，保留零值、空值、换行与天赋说明覆盖。不同网址分别保存；更换设备或网址前请导出。导入会替换当前档案；“清空当前档案”有确认框。

## 数据与计算

- `scripts/extract-workbook.py` 只读提取原 Excel 的值、展开共享公式、缓存、命名区域、保护、合并、扩展数据校验与条件格式，生成 `web/data/workbook.json`。提取使用 Python 的 `openpyxl` 与标准库 XML 工具，不保存原工作簿。
- `web/engine.js` 直接解析提取的公式并实时计算。预算、职业资源、天赋说明均来自工作簿，没有另写一套规则数值。错误结果保留 Excel 错误标记；不使用保存缓存代替实时计算。
- 主属性、主技能高亮和资源超限提示直接采用原卡条件格式表达式。配色调整为网页铜金色；原表遗漏吸血鬼猎人的超限提示范围也保留并注明。
- 6 张原表、440 个非空常量、102 个公式、13 个命名区域、110 个可编辑字段均包含在提取资料中。天赋、资产和纪念物三张可见参考表在网页中完整呈现，隐藏辅助表的泛型资料及更新记录在核验说明中可查。
- [工作簿清单](web-card-workbook.md)记录所有字段与公式；[规则核验](web-card-rules-audit.md)记录准确规则书页码、已确认差异和扩展资料缺口。

JSON 档案格式为 `vaesen-web-card`，版本 1。工作簿 SHA-256 校验不同版本，输入键格式为 `角色卡!D16`。导入只接受原表可编辑区域的标量值，不能覆盖锁定公式或查表资料。`0`、`null` 和公式说明的空字符串彼此区分。

## 验证

`npm test` 的期望数据由 `scripts/extract-workbook-reference.py` 直接从原始 OOXML 独立提取，保存在 `test/fixtures/workbook-reference.json`，不从网页计算引擎生成答案。

验证覆盖全部 102 个公式初始结果、440 个源值、110 个编辑区域、年龄边界、11 个泛型、57 个天赋、8 档生活标准，以及负余额、分数、文本数值、空白、零、错误传播、动态下拉和存档迁移。缓存对齐只是基线；输入变化另有独立预期验证。没有使用桌面 Excel 或 LibreOffice 做批量重算；当前结论基于原始公式、原表缓存、独立预期与浏览器试填。

当前共 72 项测试，全部通过，另覆盖原表实际条件格式的 11 个泛型高亮和资源超限提示边界。`npm run build` 与 `git diff --check` 通过；原 Excel 的 SHA-256 未变。

浏览器试填验证了：年龄与属性/技能/资源联动、职业天赋切换、手写说明恢复、状态和经验独立性、刷新恢复、JSON 导入、错误版本导入保持当前状态、导出成功提示、清空确认、57/8/36 项参考表和 110 个输入区域。桌面及 390px 手机视口已检查；手机页面无整体横向溢出，装备和武器表按需横向滚动。

网页在支持 `document.modelContext` 的浏览器中还会注册两个可选 WebMCP 工具：`read_investigator_card` 和 `update_investigator_fields`，共用同一输入与计算流程。当前核验浏览器未支持该接口，原生 WebMCP 注册和调用未能实测；普通网页功能不依赖它。

## 构建

`npm run build` 将源码及资料复制到 `web/dist/`，无服务器计算依赖。源文件夹中 `.openai/hosting.json` 保存此网页的 Sites 身份，静态发布目录为 `dist`。发布准备使用独立的忽略目录，不改动本仓库 Git 历史。

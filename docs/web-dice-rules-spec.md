# 网页卡：骰池与战斗数值规则规范

依据仓库内《北欧奇谭规则书》中文版本。下文页码同时注明原书页码与 PDF 页码。原 Excel 的计算结果继续由原始回归测试保存；本规范用于当前网页的规则计算。角色通过常规建卡进入成长，档案只接受当前规则版 v2。

## 1. 技能、属性与状态

| 技能 | 属性 | 原卡属性 / 技能单元格 | 对应状态 |
| --- | --- | --- | --- |
| 敏捷 | 体能 | D20 / D21 | 物理 |
| 近身战斗 | 体能 | D20 / D22 | 物理 |
| 力量 | 体能 | D20 / D23 | 物理 |
| 医学 | 精准 | I20 / I21 | 物理 |
| 远程战斗 | 精准 | I20 / I22 | 物理 |
| 隐秘行动 | 精准 | I20 / I23 | 物理 |
| 调查 | 逻辑 | N20 / N21 | 精神 |
| 学习 | 逻辑 | N20 / N22 | 精神 |
| 警觉 | 逻辑 | N20 / N23 | 精神 |
| 启迪 | 共情 | S20 / S21 | 精神 |
| 操控人心 | 共情 | S20 / S22 | 精神 |
| 观察 | 共情 | S20 / S23 | 精神 |

基础骰池为对应属性值加技能值。技能为 0 仍可检定，仅使用属性骰；每枚 D6 的 6 是一个成功。表格与规则来源：[技能检定，原书 38 页 / PDF 42 页](rulebook/03-skills.md#section-01)。

物理普通状态只数 Y10、Y11、Y12 的 ●；精神普通状态只数 AD10、AD11、AD12 的 ●。○、空白不增加状态数。物理状态影响体能、精准；精神状态影响逻辑、共情；每个对应状态扣 1 骰，累计扣除。Y13 / AD13 是崩溃开关，不能当成第四个普通扣骰项。[状态，原书 40 页 / PDF 44 页](rulebook/03-skills.md#section-05)。

设 `A` 为对应属性，`S` 为对应技能，`C` 为对应普通状态数，`I` 为本次是否无视对应状态，`T` 为本次适用的天赋加成，`E` 为本次实际使用的装备加成，`W` 为本次实际使用的武器奖励，`H` 为经 GM 认可的帮助骰，`V` 为本次使用的优势，`M` 为其他明确调整值，`P` 为适用的护甲敏捷调整值：

```text
技能原始骰池 = A + S + T + E + W + min(3, H) + (使用优势 ? 2 : 0) + M + P - (I ? 0 : C)
可进行检定时的骰数 = max(1, 技能原始骰池)
```

所有适用调整值相加，不能只选择最大的一个；帮助最多 +3；优势 +2，必须在检定或孤注一掷之前声明，每次游戏只能使用一次。装备奖励必须针对正在执行的动作成立；表中的奖励大多为 +1 至 +3。[运用调整值，原书 38 页 / PDF 42 页](rulebook/03-skills.md#section-01)，[彼此帮助，原书 41 页 / PDF 45 页](rulebook/03-skills.md#section-07)，[优势，原书 42 页 / PDF 46 页](rulebook/03-skills.md#section-10)，[装备，原书 43 页 / PDF 47 页](rulebook/03-skills.md#section-11)。

`max(1, …)` 依据状态规则中至少保留一骰的条文；它不能让崩溃者恢复行动。原文没有另列一个护甲把骰数减到 0 时的例外，网页统一使用一骰下限，并单独处理行动资格。缺失或非数值属性应显示未完成输入；技能空白可以作为尚未分配的 0；属性必须为 2–5 的整数，技能必须为 0–5 的整数，建卡阶段还须遵守主要属性、主要技能与预算限制。非法数值产生校验信息，不能静默改写存档。[状态，原书 40 页 / PDF 44 页](rulebook/03-skills.md#section-05)，[属性、技能范围，原书 20–21 页 / PDF 24–25 页](rulebook/02-player-characters.md#section-09)。

## 2. 崩溃与孤注一掷

当已经承受三个同类普通状态、再承受一个状态时，角色崩溃；仅有三个状态不会自动崩溃。某些严重情景可以直接造成崩溃，因此不要因为用户独立勾选崩溃格就强制补勾三个普通状态。[检定失败，原书 39 页 / PDF 43 页](rulebook/03-skills.md#section-03)，[状态，原书 40 页 / PDF 44 页](rulebook/03-skills.md#section-05)。

| 崩溃类型 | 检定资格 |
| --- | --- |
| 物理崩溃 | 所有检定自动失败；不能显示成仍可投 1 骰的正常技能检定 |
| 精神崩溃 | 受到攻击时允许逃跑、格挡、闪避；不能攻击或执行仪式，不能把一般技能表当成正常可行动列表 |

精神崩溃下可以移动和说话；获准的防御检定如常生效，仍按相应状态和调整值计算。无视状态的天赋只免除对应扣骰，不能解除崩溃的行动限制。[崩溃，原书 63–64 页 / PDF 67–68 页](rulebook/05-conflict-and-injuries.md#section-16)。

孤注一掷每个行动一次，重投所有不是 6 的骰子。它新增的状态在这次重投结束后才生效；不能先扣掉新状态的骰子。即使新状态将导致崩溃，这一次重投仍然有效。普通成功的检定也可以为了更多成功而孤注一掷。[孤注一掷及崩溃前的孤注一掷，原书 39 页 / PDF 43 页](rulebook/03-skills.md#section-04)。

## 3. 恐惧检定

恐惧检定使用玩家选择的逻辑或共情属性，不添加调查、启迪或任何其他技能值。只扣精神普通状态。可提供支持的同伴数最多给 +3；恐惧或崩溃的角色不能为他人提供此奖励；战斗中必须同一区域。[恐惧，原书 68 页 / PDF 72 页](rulebook/05-conflict-and-injuries.md#section-19)。

```text
恐惧原始骰池 = 选择的逻辑或共情 + min(3, 合格同伴数) + 勇敢奖励 + 本次其他适用奖励 - 精神状态数
恐惧骰数 = max(1, 恐惧原始骰池)，前提是角色仍可进行该检定
所需成功数 = 当前生物、魔法或事件的恐惧值
未抵消的精神状态数 = max(0, 恐惧值 - 已骰成功数)
```

网页的“合格同伴数”应明确表示为自己提供支持的其他 PC，不能把自己作为支持者重复计入。中文原文写“场景内玩家数量”，随后规定不能“为他人”提供奖励；上述输入命名是对支持关系的明确化。存在两名 PC 不等于有两名合格支持者；“人多壮胆”的在场人数条件与恐惧支持骰的合格人数应分别处理。[恐惧，原书 68 页 / PDF 72 页](rulebook/05-conflict-and-injuries.md#section-19)，[人多壮胆，原书 55 页 / PDF 59 页](rulebook/04-talents.md#section-61)。

失败会导致恐慌；其持续回合为另投的 D6，不能从失败的骰池自动推断。额外成功不会进一步改善恐惧结果。勇敢总是使恐惧检定 +1；军医、忠诚、人多壮胆需要对应情景成立才启用。[恐惧，原书 68 页 / PDF 72 页](rulebook/05-conflict-and-injuries.md#section-19)，[勇敢，原书 54 页 / PDF 58 页](rulebook/04-talents.md#section-43)。

## 4. 护甲、武器与伤害

| 护甲 | 防护骰 | 敏捷调整 |
| --- | --- | --- |
| 轻甲 | 2 | -1 |
| 中甲 | 4 | -2 |
| 重甲 | 6 | -3 |

穿戴护甲只为敏捷检定加入表中的负调整，不能减少所有物理技能。防护骰等于保护值，独立于属性与技能；每个防护成功抵消一点伤害。防护值不能当作技能奖励或固定减伤。掩体也提供独立防护骰；一般不能防护来自同区域的攻击，但同区域的爆炸可以使用掩体，护甲不能抵御爆炸。原文没有要求护甲防护骰扣状态；网页保留独立防护数据。[护甲和掩体，原书 73–74 页 / PDF 77–78 页](rulebook/05-conflict-and-injuries.md#section-33)，[爆炸，原书 69 页 / PDF 73 页](rulebook/05-conflict-and-injuries.md#section-20)。

武器表的“奖励”是攻击检定额外骰，“伤害”是命中后造成的状态数；两者不能相加充当骰池。攻击使用所选武器对应技能，额外成功可以各自增加一点伤害，也可以购买其他效果，所以不能默认把所有额外成功都用于伤害。多件武器或装备放在背包里不意味着全部同时使用，检定面板应选择本次使用项。[攻击，原书 60 页 / PDF 64 页](rulebook/05-conflict-and-injuries.md#section-09)，[装备和武器，原书 74 页 / PDF 78 页](rulebook/05-conflict-and-injuries.md#section-34)。

徒手拳击/踢击使用力量，伤害 1，奖励 0；拳击手使徒手伤害 +1，不增加骰子。强硬如钉在徒手力量检定中 +2，不增加伤害。神圣象征允许通过启迪检定攻击自在之物，伤害 1；它不是所有启迪检定的常驻奖励。[近战武器表，原书 77 页 / PDF 81 页](rulebook/05-conflict-and-injuries.md#pdf-page-81)，[强硬如钉，原书 53 页 / PDF 57 页](rulebook/04-talents.md#section-31)，[拳击手、神圣象征，原书 55 页 / PDF 59 页](rulebook/04-talents.md#section-60)。

## 5. 天赋的自动与情景效果

以下天赋的技能扣骰豁免可以在拥有天赋后直接应用；它们不会解除崩溃的行动限制：

| 天赋 | 自动作用 |
| --- | --- |
| 知识是可靠的 | 学习忽略对应状态 |
| 应急医学 | 医学忽略对应状态，见下方译注 |
| 绅士 | 操控人心忽略精神状态 |
| 专注 | 调查忽略对应状态 |
| 疑心 | 警觉忽略对应状态 |
| 墨客 | 启迪忽略对应状态 |
| 同理心 | 观察忽略对应状态 |
| 勇敢 | 恐惧 +1 |
| 富有 | 资源 +1，可重复购买；技能点预算不因该奖励额外扣 1 |

来源：[知识是可靠的、应急医学，原书 50 页 / PDF 54 页](rulebook/04-talents.md#section-04)，[绅士，原书 52 页 / PDF 56 页](rulebook/04-talents.md#section-19)，[专注、疑心、墨客，原书 53 页 / PDF 57 页](rulebook/04-talents.md#section-28)，[勇敢，原书 54 页 / PDF 58 页](rulebook/04-talents.md#section-43)，[同理心、富有，原书 55 页 / PDF 59 页](rulebook/04-talents.md#section-52)。

“应急医学”的中文正文写医学检定无视状态，译注指出英文原文仅无视精神状态，医学改为精准后留下了冲突且官方未勘误。采用仓库中文正文时，免除医学对应的物理状态惩罚；需要在核验说明中公开这一处理依据，不应称为官方英文勘误。[应急医学及译注，原书 50 页 / PDF 54 页](rulebook/04-talents.md#section-08)。

其余数值效果必须由检定情景或明确的单次使用标记激活：书虫、军医、寻血犬、神射手、鹰眼、忠诚、强硬如钉、流浪者戏法、战场经历、近战训练、骗术专精、炸药专家、名望、宠物、人多壮胆、短跑选手、主的牧羊人等。坚韧每次游戏一次无视状态；献身每次游戏一次无视精神状态；逃脱大师仅在敏捷用于逃离时生效。这些能力不能在技能表的普通骰池上全部永久叠加。[天赋，原书 50–55 页 / PDF 54–59 页](rulebook/04-talents.md#section-01)。

魔术手法、忏悔者、记者是在指定情景下替换使用技能；替换后使用新技能的属性与状态类别。祝福提供可消费的 +2 优势，不是施术者所有技能的永久 +2；战术家的额外成功为另一个遵从命令的角色的下一次检定提供 +2。主任医师和赦免修改治疗效果；久经沙场、防御专精、疾行、风驰电掣、命大等修改先攻、动作或结果处理，不应误加到骰池。[对应天赋条目，原书 51–55 页 / PDF 55–59 页](rulebook/04-talents.md#section-14)。

中文规则书名称“人多壮胆”与 Excel 的“人多胆壮”应作为同一天赋的兼容别名。吸血鬼猎人三个天赋不在当前基础规则书中；扩展效果必须标记来自 Excel 的扩展资料，不能宣称由这本基础规则书核验。[人多壮胆，原书 55 页 / PDF 59 页](rulebook/04-talents.md#section-61)，[基础范型范围，原书 25 页 / PDF 29 页](rulebook/02-player-characters.md#section-20)。

## 6. 当前规则计算的独立测试例

以下期望是本规范依据原文直接计算的数值，不得从 RulesEngine 的输出生成：

| 输入 | 期望 |
| --- | --- |
| 体能 3，敏捷 2，两个物理状态，一个精神状态 | 敏捷 3 骰 |
| 精准 4，远程战斗 0，一个物理状态 | 远程战斗 3 骰 |
| 逻辑 4，调查 2，两个精神状态，三个物理状态 | 调查 4 骰 |
| 上例拥有专注 | 调查 6 骰 |
| 体能 2，敏捷 0，三个物理状态 | 仍可行动时 1 骰 |
| 体能 3，敏捷 2，无状态，穿轻甲 | 敏捷 4 骰；近身战斗不扣护甲敏捷 |
| 体能 3，近身战斗 2，剑/军刀奖励 +2，两个物理状态 | 攻击 5 骰；基础伤害 2 |
| 上例使用优势 +2、一次适用天赋 +2、1 人有效帮助 | 攻击 10 骰 |
| 体能 3，力量 2，徒手并有强硬如钉、拳击手，1 个物理状态 | 力量攻击 6 骰；基础伤害 2 |
| 逻辑 4，两个精神状态，勇敢，4 名合格支持者 | 恐惧 6 骰，与调查值无关 |
| 上例没有选中勇敢 | 恐惧 5 骰 |
| 恐惧值 3，获得 1 个成功 | 新增两个精神状态 |
| 精神崩溃、物理未崩溃 | 普通攻击不可进行；在受到攻击时允许逃跑/闪避/格挡 |
| 物理崩溃并有专注 | 调查仍自动失败 |
| 穿重甲保护 6 | 防护独立投 6 骰，不增加技能池或直接减 6 伤害 |

资源与资产也有明确独立期望：资源 1–8 的交易调整值依次为 `[-1,0,0,1,1,2,3,5]`，基础资产依次为 `[0,0,1,2,3,5,8,12]`，其中表格的“—”在可花费数值中按 0 表示，文字可显示无资产。创建时资源加点按每点消耗 1 技能点；成长后每次购买富有增加 1 资源。初始职业资源范围约束创建分配，不应直接当成每次成长后购买富有的职业封顶规则。[初始资源，原书 21–22 页 / PDF 25–26 页](rulebook/02-player-characters.md#section-14)，[资源调整值，原书 73 页 / PDF 77 页](rulebook/05-conflict-and-injuries.md#section-33)，[富有，原书 55 页 / PDF 59 页](rulebook/04-talents.md#section-65)。

参与本次游戏固定获得 1 XP，再对第 2–8 题每个“是”各加 1：`本场 XP = 1 + 第 2–8 题的 ● 数`。因此第一格 ○/空白而其余两格 ● 时仍得 3 XP，不能实现为 `max(1, 八格 ● 总数)`。5 XP 换一次技能提升一级或购买一个天赋；技能最多 5。八个圆点可以表达本场回答，但不能同时自动重复计入既有 XP 总额与未结算本场 XP。[经验，原书 25 页 / PDF 29 页](rulebook/02-player-characters.md#section-19)。
